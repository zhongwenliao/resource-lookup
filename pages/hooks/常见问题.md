## Chat GPT 的对话功能实现，为什么使用 SSE 协议而不是Websocket 协议？

    1. SSE 协议是基于 HTTP 协议的，而 Websocket 协议是基于 TCP 协议的。
    2. SSE 协议是单向的，只能由客户端向服务器发送请求，而 Websocket 协议是双向的，客户端和服务器可以同时发送请求和响应。
    3. SSE 协议是基于文本的，而 Websocket 协议是基于二进制的。
    4. SSE 协议是轻量级的，而 Websocket 协议是重量级的。

## 如何进行图片优化

    1. 压缩图片：使用压缩工具压缩图片，如 tinypng.com 等。
       1. 有损压缩 ：适当降低图片质量
       2. 无损压缩 ：不压缩图片质量，只压缩文件大小
       3. 自定义压缩
    2. 图片格式转换：将图片格式转换为 WebP 格式，因为 WebP 格式支持有损压缩和透明度，压缩率高，加载速度快。
       1. webp 格式支持有损压缩和透明度，压缩率高，加载速度快。
       2. avif 格式支持有损压缩和透明度，压缩率高，加载速度快。
       3. jpeg 格式不支持透明度，压缩率低，加载速度慢。适合图片和复杂对象
       4. png 格式不支持有损压缩，压缩率低，加载速度慢。适合透明度图像
       5. svg 格式不支持压缩，压缩率低，加载速度慢。适合图标和简单图形
    3. 图片懒加载：使用图片懒加载技术，只有当图片进入视口时才加载图片，避免加载过多图片导致页面加载缓慢。
       1. loading 图片占位符
       2. load 事件监听
       3. intersectionObserver 监听图片是否进入视口
       4. 第三方库：如 lazysizes、lazysizes-avif 等
    4. 图片 CDN 加速：将图片上传到 CDN 上，利用 CDN 加速图片加载，提高图片加载速度。
       1. CDN: 内容分发网络，将图片缓存到多个节点上，用户请求图片时，根据用户位置选择最近的节点返回图片，提高图片加载速度。
       2. 配置 CDN 缓存策略：根据图片的访问频率和更新频率，配置 CDN 缓存策略，如缓存时间、缓存刷新策略等。
