# 码对绑定与汇总二维码（pair-code-binding）

## ADDED Requirements

### Requirement: 产品数字码与标签码 1:1 绑定

用户通过扫描（或手动输入）产品上唯一的一段**数字码**，再扫描（或输入）另一段**标签码**，建立两码的 1:1 绑定。绑定存本机数据库，一个数字码只绑一个标签码、一个标签码只挂一个数字码。

#### Scenario: 两步扫码绑定

- **WHEN** 用户扫描/输入数字码（纯数字校验通过）后，页面进入「待扫标签码」状态，再扫描/输入标签码
- **THEN** 码对写入本机 `pair-bindings` 仓库（含两码、所属文档、绑定时间），提示成功并回到「待扫数字码」状态
- **AND** 摄像头连续扫码、扫码枪（键盘模式）、手动输入三通道共用同一状态机，扫码枪无需聚焦输入框

#### Scenario: 数字码格式校验

- **WHEN** 第一步扫描到的内容不是纯数字（或少于 4 位）
- **THEN** 拒绝进入下一步并提示原因，已录入状态保持不变

#### Scenario: 已绑定的码拒绝重复绑定

- **WHEN** 扫描的数字码已绑定其他标签码，或标签码已绑定其他数字码
- **THEN** 提示既有绑定关系并跳过本次绑定（重绑需先在绑定记录中删除，防止误覆盖）

#### Scenario: 绑定双向可查

- **WHEN** 溯源查询页输入/扫描该数字码或该标签码（无论先扫哪个方向）
- **THEN** 均能查到这组码对绑定关系

### Requirement: 绑定归属文档并可导出清单

码对绑定归属到命名**文档**（分组单位），文档内容可导出为 Excel 绑定清单，清单上同时体现数字码与标签码。

#### Scenario: 文档管理

- **WHEN** 用户新建/改名/删除文档
- **THEN** 文档记录落 `bind-docs` 仓库；改名同步刷新其下码对的文档名快照；删除文档时明确提示将级联删除其下全部码对绑定，确认后同事务原子清理

#### Scenario: 导出绑定清单 Excel

- **WHEN** 用户在绑定记录区点击导出（按当前文档筛选范围）
- **THEN** 生成 xlsx 清单：标题行（系统名 + 清单名）、文档与导出时间信息行、明细列（序号/数字码/标签码/所属文档/绑定时间）
- **AND** 桌面版弹出系统保存对话框写盘（二进制写文件）；浏览器调试模式降级为浏览器下载

### Requirement: 多文档数字码汇总为单个二维码

用户把**多个文档**上的数字码（以及扫码/手动追加的数字码）汇总绑定到**一个二维码**上。二维码内容自包含全部数字码：通用扫码器扫描即可读出绑定的全部数字码；本系统扫描则进一步关联出每个数字码的标签码与文档。

#### Scenario: 从多文档取数生成汇总码

- **WHEN** 用户多选来源文档并载入，勾选成员（默认全选，可剔除）后点击生成
- **THEN** 生成内容为「`HYX-AGG` 标识行 + 每行一个数字码」的二维码，成员去重、全为纯数字码
- **AND** 二维码可预览、下载 PNG、复制内容；汇总关系落 `agg-codes` 仓库（标题/成员/来源文档/创建时间）

#### Scenario: 通用扫码器可读出全部数字码

- **WHEN** 用任何标准二维码扫码器扫描汇总码
- **THEN** 读出多行文本：首行为 `HYX-AGG` 标识行，其后每行一个数字码（不依赖本软件即可核对成员）

#### Scenario: 汇总成员扫码添加

- **WHEN** 用户摄像头连续扫码或手动输入数字码追加成员
- **THEN** 非纯数字内容拒绝并提示；重复成员自动去重

#### Scenario: 历史汇总码

- **WHEN** 用户查看历史汇总码列表
- **THEN** 展示标题/成员数/创建时间，可重新生成二维码预览、查看成员明细、删除（删除仅删汇总关系，不影响码对绑定）

## MODIFIED Requirements

### Requirement: 溯源查询关联检索

**FROM**: 输入或扫码获取码值后，先检索记录绑定库（code-bindings）展示绑定检测记录；未绑定再按明文/规则码解析。

**TO**: 输入或扫码获取内容后，按顺序关联检索：① 汇总码内容（多行 `HYX-AGG`）→ 展示汇总标题、来源文档与全部成员数字码，并逐个关联出成员绑定的标签码；② 记录绑定库（原行为）；③ 码对绑定库（数字码与标签码双向）→ 展示码对关系、所属文档与绑定时间；④ 汇总成员反查 → 展示该数字码所在的历史汇总码；⑤ 回退明文/规则码解析（原行为）。

#### Scenario: 扫描汇总码

- **WHEN** 查询页扫描/粘贴汇总码内容（多行、首行 `HYX-AGG`）
- **THEN** 展示汇总标题与成员表格：每个数字码对应其绑定的标签码与所属文档（未绑定的数字码也列出并标注）
- **AND** 内容与 `agg-codes` 库中记录一致时展示落库标题；不在库中时按内容解析展示（外来汇总码仍可读）

#### Scenario: 扫描数字码

- **WHEN** 查询页扫描/输入一个已建立码对绑定的数字码
- **THEN** 展示其绑定的标签码、所属文档、绑定时间，以及包含它的全部历史汇总码
- **AND** 未建立码对绑定但出现在某些汇总码中的数字码，展示所在汇总码列表

#### Scenario: 扫描标签码

- **WHEN** 查询页扫描/输入一个已建立码对绑定的标签码（含本系统规则码）
- **THEN** 展示其绑定的数字码、所属文档、绑定时间与所在汇总码；不再报「无法识别」

#### Scenario: 未绑定的码回退原流程

- **WHEN** 查询页输入的码未命中汇总码/记录绑定/码对绑定
- **THEN** 回退明文文本/编码规则两种模式解析（行为与改动前一致）
