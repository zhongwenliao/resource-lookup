- [x] 2.1 新建 `src/common/qr-parse.js`：实现 `parseQrContent(text)`，按设计 D3 顺序识别 url / text / rule 三种模式，返回 `{ mode, data }` 或 `{ mode: 'unknown', error }`；url 模式解码失败直接报错不回退。验证：构造三种模式样例输入 + 损坏链接 + 乱文本，逐例核对返回值
- [x] 2.2 明文解析：按「型号:/序号:/时间:/判定:/测量:」行前缀提取字段，测量值按逗号拆分为数组；缺失行容错为空。验证：完整明文与缺测量行两种输入解析正确
- [x] 2.3 规则码前缀拆分：内置组件词表匹配拆分「项目+组件」，匹配不到返回合并前缀并标记 `prefixAmbiguous: true`。验证：样例码 `King12-Basic中框3QABC691400001` 拆出项目 `King12-Basic`、组件 `中框`；无词表命中码返回合并前缀
- [x] 2.4 规则码关联数据查询：查询页规则码结果在逐段含义之外调用 `qc-db.js` 的 `findByRuleCode(code)` 回查本地批次（接口由 `qr-code-generation` 变更落地），命中展示记录（序号/时间/判定/测量值）与所属批次（文件名/型号/导入时间），多批次命中全部列出，未命中提示无关联记录。验证：生成端产出的规则码可回查到对应记录；任意拼码未入库时仅展示拆段含义
