# 扫码绑定表格数据（qr-bind-table-data）

## ADDED Requirements

### Requirement: 逐个扫码绑定表格行

选定检测数据表格（桌面版选择文件实时读取，不导入批次；浏览器调试模式降级为上传快照）后，用户逐个扫描实物二维码并在记录表格中点选对应行，确认后建立「码值 ↔ 记录」绑定。

#### Scenario: 选定数据源文件实时读取

- **WHEN** 用户在绑定页（桌面版）选择检测数据表格文件
- **THEN** 立即读取并解析展示记录表格（与生成页共用同一套列识别逻辑），文件路径记忆在本机，重进页面自动恢复
- **AND** 不写入本机批次库（`import-batches` 不产生新批次）

#### Scenario: 检测数据更新自动刷新

- **WHEN** 数据源文件被检测设备持续写入（mtime 变化）
- **THEN** 绑定页轮询感知后自动重读刷新表格（默认每 3 秒探测一次，可手动暂停/立即刷新）
- **AND** 刷新后已选行按序号重新定位，定位不到则清空待选行（避免绑到已不存在的行）
- **AND** 设备写一半导致的读取/解析失败静默跳过，保留旧数据等下一轮重试，不打断绑定操作

#### Scenario: 数据源文件失效

- **WHEN** 数据源文件被移动或删除（stat 探测失败）
- **THEN** 暂停实时监听并提示原因，已读取的数据保留展示，用户可重新选择文件恢复

#### Scenario: 扫码并选行绑定

- **WHEN** 用户摄像头扫码（或手动输入码值）后在记录表格中点选一行并点击「确认绑定」
- **THEN** 绑定关系写入本机 `code-bindings` 仓库（含码值、数据源标识、记录快照、绑定时间）
- **AND** 该行标记为已绑定并展示绑定码值，待绑定码清空，可继续扫下一个

#### Scenario: 外部码原样绑定

- **WHEN** 扫描的码值不满足任何已知内容模式（外部供应商码等）
- **THEN** 码值原样存储（不解析、不校验格式），绑定与查询行为与规则码一致

#### Scenario: 一码一行重绑覆盖

- **WHEN** 确认绑定的码值已绑定其他记录行（或所选行已绑定其他码值）
- **THEN** 界面先提示已绑定的旧关系，用户确认后覆盖旧绑定（同一码只指向一条记录、一条记录只挂一个码）

#### Scenario: 解绑

- **WHEN** 用户在已绑定行或绑定记录列表上执行解绑/删除
- **THEN** 该绑定从本机删除，行绑定标记与列表同步刷新；数据源文件不受影响

### Requirement: 绑定关系独立于数据源留存

绑定存记录快照（序号/时间/判定/测量值）而非对批次或文件的引用。

#### Scenario: 数据源文件删除后绑定仍可查

- **WHEN** 绑定建立后其数据源文件被删除或更换
- **THEN** 溯源查询页扫描该码仍能展示绑定的记录数据（快照自包含）

#### Scenario: 旧批次模式绑定向后兼容

- **WHEN** 本机存在旧版（批次导入模式）建立的绑定记录
- **THEN** 绑定列表与溯源查询仍按原来源批次文件名展示，查询行为不受影响

## MODIFIED Requirements

### Requirement: 溯源查询优先检索绑定库

**FROM**: 输入或扫码获取码值后，按明文文本/编码规则两种模式解析展示溯源信息；编码规则码按码回查本地批次关联记录。

**TO**: 输入或扫码获取码值后，先检索本机绑定库（任何码值都可能已绑定，含外部码与规则码），命中直接展示绑定的记录（序号/时间/判定/测量值/来源数据源/绑定时间）；未绑定再按明文文本/编码规则两种模式解析展示，编码规则码按码回查本地批次关联记录。

#### Scenario: 扫描已绑定的外部码

- **WHEN** 查询页扫描一个已建立绑定的外部码（不满足任何解析模式）
- **THEN** 直接展示该码绑定的检测记录与来源数据源信息，不报「无法识别」

#### Scenario: 扫描未绑定的码

- **WHEN** 查询页扫描一个未建立绑定的码值
- **THEN** 回退现有模式解析流程（明文/规则码拆段/规则码关联回查），行为与改动前一致
