# 钻潜交易体系 · 规则化回测与信号扫描

`zuanqian.py` 把「横盘做突破 + 动能确认 + 量价配合 + 趋势过滤 + 固定风险仓位」这套价格行为交易规则写成可回测、可扫描的程序，用来验证策略思想在 A 股历史数据上的统计表现。

- 数据源：腾讯财经日 K 接口（前复权）
- 依赖：**零第三方依赖**，Python 3.8+ 标准库即可运行
- 自选股：复用 `stocks.json` 与 `src/*.md` 文件名映射

---

## 快速开始

```powershell
# 1. 回测 src/ 全部自选股（输出汇总表）
python zuanqian.py

# 2. 回测指定标的（代码或名称，含逐笔交易明细）
python zuanqian.py 600030
python zuanqian.py 万华化学 600030

# 3. 只扫描最近 3 个交易日的信号（不回测）
python zuanqian.py 600030 --scan

# 4. 多标的时也输出完整交易明细
python zuanqian.py --full

# 5. 调参回测
python zuanqian.py 600030 --risk 0.5 --tp1 1.5 --tp2 2.5 --days 400

# 6. 扫描信号并导出止盈止损表格（CSV，Excel 可直接打开）
python zuanqian.py 600030 000001 --scan --csv 止盈止损.csv
```

> 标的解析规则：6 位代码自动推断交易所前缀（`569`→sh，`0123`→sz，`48`→bj）；中文名称先查 `stocks.json`（名称→代码），再匹配 `src/*.md` 文件名。找不到时会提示补充映射。

## 可视化界面：`gui.py`

不想敲命令行，可以双击 `启动界面.bat`（或 `python gui.py`）：本机起一个零依赖的本地服务并自动打开浏览器，与 `zuanqian.py` 共用同一套规则引擎，口径完全一致。

- **信号扫描**：输入任意代码/名称（多只用逗号分隔，支持中文名称自动补全），表格展示最近 3 个交易日的状态、触发价、止损、两档止盈、建议股数与仓位，一键导出 CSV；点行内「回测」直接对该标的回测
- **回测分析**：统计卡片（总收益/最大回撤/胜率/平均R/盈亏比/买入持有基准）+ K 线买卖点图（箱体通道、EMA20/60、B/S 买卖点、未成交信号标记、每笔持仓的止损/止盈线，支持滚轮缩放、拖动平移、悬停查看明细）+ 权益曲线（策略 vs 买入持有）+ 交易明细表（可导出 CSV）
- 界面上方参数栏（K线数/资金/单笔风险/止盈R/止损上限）改动后点按钮即按新参数计算

```powershell
python gui.py                # 默认 http://127.0.0.1:8666，自动开浏览器
python gui.py --port 9000    # 指定端口
```

## 策略规则（全部可参数化）

| # | 规则 | 程序化定义 |
|---|------|-----------|
| 1 | 趋势定义（多周期共振） | 日线收盘 > EMA60 且 EMA 上行；周线收盘 > 周线 EMA8 |
| 2 | "两类行情不做" | 趋势向下不做；ATR 占比 > 7%（波动极端）不做 |
| 3 | 横盘箱体 | 最近 6~25 根 K 线高低点区间 ≤ 3 × ATR(14) |
| 4 | 动能突破 | 阳线实体 ≥ 1 × ATR，收盘突破箱体上沿且未远离（< 1 × ATR，防追高） |
| 5 | 量价配合 | 突破日成交量 ≥ 1.5 × 20 日均量，且收盘位于 K 线上部 60% |
| 6 | 入场 | 信号次日开盘价买入 |
| 7 | 止损 | 箱体下沿 − 0.2 × ATR（结构破坏）；过窄则放宽至 1 × ATR |
| 8 | 止盈 | 达 2R 减半仓并将止损上移至成本；其余在 3R 或收盘跌破 EMA20 离场 |
| 9 | 资金管理 | 单笔风险 = 资金 × 1%，按止损距离反推股数（100 股整手，不加杠杆） |
| 10 | 规则化执行 | T+1、佣金万 3 / 印花税万 5（卖出）、60 根 K 线时间止损，全程无主观干预 |

## 参数一览

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--days` | 600 | 取多少根日 K（回测/扫描范围） |
| `--capital` | 1000000 | 初始资金（元） |
| `--risk` | 1.0 | 单笔风险占资金百分比 |
| `--commission` | 0.0003 | 佣金率（双边） |
| `--stamp` | 0.0005 | 印花税率（仅卖出） |
| `--ema-trend` | 60 | 日线趋势 EMA 周期 |
| `--weekly-ema` | 8 | 周线趋势 EMA 周期 |
| `--box-min` / `--box-max` | 6 / 25 | 横盘箱体 K 线数范围 |
| `--box-atr` | 3.0 | 箱体宽度上限（倍数 × ATR） |
| `--body-atr` | 1.0 | 突破阳线实体下限（倍数 × ATR） |
| `--vol-mult` | 1.5 | 突破量能下限（倍数 × 20 日均量） |
| `--atr-max` | 7.0 | ATR 占比上限（%），超过不做 |
| `--chase-atr` | 1.0 | 收盘超出箱体上沿多少倍 ATR 放弃 |
| `--tp1` / `--tp2` | 2.0 / 3.0 | 第一/第二止盈的 R 倍数 |
| `--stop-buffer` | 0.2 | 止损低于箱体下沿的 ATR 缓冲 |
| `--min-stop-atr` | 1.0 | 最小止损距离（倍数 × ATR） |
| `--max-stop-pct` | 12.0 | 止损距离占现价上限（%），超过放弃 |
| `--max-hold` | 60 | 最长持仓 K 线数（时间止损） |
| `--cooldown` | 5 | 平仓后的冷却 K 线数 |
| `--scan` / `--full` | — | 扫描模式 / 多标的完整明细 |
| `--csv` | — | 扫描结果导出 CSV（配合 `--scan`，含止盈止损位与建议股数） |
| `--watch-dist` | 3.0 | 预备箱体距触发价上限（%） |

## 输出说明

**回测报告**（单标的或 `--full`）：

```
期末权益    1,086,420（+8.64%）   基准买入持有: +12.30%
最大回撤    -6.20%
交易次数    23   胜率 47.8%   平均R +0.31   盈亏比 1.85
#    买入日      卖出日      买入价    卖出价    股数    净盈亏      R       天   出场
1    2025-07-24  2025-10-24  28.58     29.17     5000    +2790       +0.28   60   时间止损
```

- **R 倍数**：净盈亏 ÷ 初始风险额（股数 × 止损距离），衡量每笔交易相对风险的收益
- **出场原因**：止损 / 保本止损 / 止盈2R减半 / 止盈3R / EMA20跟踪离场 / 时间止损
- **基准**：同期买入持有收益，用于对比策略表现

**信号扫描**（`--scan`）：显示趋势状态、ATR 占比，最近 3 个交易日内有信号则给出箱体区间、止损位与两档止盈位；趋势与箱体就绪、收盘距触发价 `--watch-dist`（默认 3%）以内的给出「预备箱体」触发价与计划止盈止损；无信号则给出未触发原因（趋势过滤未通过 / 无有效横盘箱体 / 量能不足等）。加 `--csv 文件名` 可把全部标的（含无信号原因、建议股数与仓位）导出为 CSV，Excel 可直接打开。

## 全市场选股：`screener.py`

把同一套规则用于全市场扫描：拉取全部 A 股列表（东财接口，含行业/成交额/流通市值快照）→ 预筛（剔除 ST/退市/次新/停牌/低流动性）→ 多线程逐只检查日 K → 输出触发「钻潜突破」的股票及箱体/止损/止盈/建议仓位。

```powershell
# 全市场突破信号（默认预筛约 3000 只，约 1~2 分钟，视网络而定）
python screener.py

# 预备箱体模式：趋势与箱体就绪、尚未突破，给出触发价（箱体上沿）
python screener.py --watch

# 只检查指定标的
python screener.py 600030 万华化学

# 常用组合：涨幅预筛提速 + 市值下限 + 导出 CSV
python screener.py --min-chg 2 --min-cap 30 --top 60 --csv 信号.csv

# 回看最近 3 根 K 线的信号（盘中/盘后复核用）
python screener.py --lookback 3
```

要点：

- **预筛参数**：`--min-amount`（当日成交额，万元，默认 2000）、`--min-cap`（流通市值，亿元，默认不限）、`--min-price` / `--max-price`、`--min-chg`（当日涨幅下限，设置后可大幅减少需拉取 K 线的数量）、`--include-bj`（含北交所）
- **两种模式**：默认输出突破信号（按量比降序）；`--watch` 输出预备箱体候选（按距触发价升序，`--watch-dist` 控制距离上限，默认 3%）
- **输出列**：行业、量比（突破量 / 20 日均量）、箱体区间、止损、两档止盈、按 `--capital` / `--risk` 估算的建议股数与仓位占比；止损距离超过 `--max-stop-pct` 的信号会被剔除（与回测规则一致）
- **盘中提示**：盘中运行时最后一根 K 线为实时快照，收盘前信号可能变化，建议收盘后运行
- **数据源容错**：列表接口在东财多个主机间自动切换，全部不可用时自动改用腾讯备用列表（无行业字段，行业列显示 `-`）；日 K 接口同样内置备用域名。若两者都失败，多为网络/代理问题或被数据源临时限流——降低 `--workers`、稍后重试，或先用指定标的模式（`python screener.py 600030`）

## 注意事项

- 本程序是对公开流传的「钻潜」思想的**程序化近似**，并非官方课程内容；A 段、轨迹等概念仅取可量化的部分。
- 回测基于前复权数据，未包含分红送转的精确处理、涨跌停无法成交、滑点等真实约束。
- 回测结果不代表未来收益，仅供学习研究，**不构成投资建议**。
